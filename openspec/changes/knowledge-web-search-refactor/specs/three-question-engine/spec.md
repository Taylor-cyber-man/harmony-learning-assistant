## MODIFIED Requirements

### Requirement: 显示学习空间单页布局
系统 SHALL 在单页滚动布局的学习空间中，在第一问下方展示独立的"学习资料"区块，列出所有课程相关的知识条目（AI搜索、文件上传、手动添加）。

#### Scenario: 学习资料区块始终可见
- **WHEN** 用户进入学习空间页面
- **THEN** 页面布局为：知识图谱（第一问）→ 学习资料区 → 认知地图（第二问）→ 深度测试（第三问）
- **AND** 资料区展示所有该课程的知识条目列表

#### Scenario: 知识点卡片折叠展示
- **WHEN** 资料区加载完成
- **THEN** 每条知识点显示标题、来源标签（AI搜索/文件上传/手动添加）和来源色条
- **AND** 点击条目可展开查看完整内容

#### Scenario: 图谱节点联动资料高亮
- **WHEN** 用户点击知识图谱中的节点
- **THEN** 资料区中与该节点关联的知识条目高亮显示（边框变色），其他条目保持正常

#### Scenario: 资料区空状态
- **WHEN** 课程尚未添加任何知识点
- **THEN** 资料区显示"暂无学习资料，请在课程设置中添加"提示

## ADDED Requirements

### Requirement: In-line file upload in learning space
用户 SHALL 能够在学习空间资料区直接上传补充学习资料文件。

#### Scenario: 资料区上传文件
- **WHEN** 用户点击资料区底部的"上传资料"按钮
- **THEN** 系统打开文件选择器，用户选择文件后自动添加至当前课程知识库，来源标注为"文件上传"

#### Scenario: 上传后刷新列表
- **WHEN** 文件上传成功并保存至知识库
- **THEN** 资料区列表自动刷新显示新条目
