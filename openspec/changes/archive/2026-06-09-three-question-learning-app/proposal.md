## Why

当前学习工具普遍停留在"被动投喂"模式（看教材、刷题库、背重点），而MIT研究生验证的"三问高效学习法"证明：通过**核心心智模型提取 → 学术分歧挖掘 → 深度理解测试**三步走，48小时内可以掌握一门陌生学科。本产品将此方法论封装为鸿蒙原生APP，让学生通过主动提问触发课程创建、自主构建知识内容，并利用三问认知引擎实现从"知其然"到"知其所以然"的认知跃迁。时机上，华为HCIA-AI认证体系提供了天然的内容素材，而HarmonyOS NEXT API 6.0.2生态成熟度已足以支撑完整应用的开发。

## What Changes

- 从零构建一个完整的鸿蒙APP（当前工程仅有Hello World页面）
- 实现**柔性课程生成模块**：搜索框输入问题 → 自动创建课程 → 课程卡片管理（生命周期状态机：未创建/已创建/活跃/完成）
- 实现**复合知识库构建**：手动输入知识点 + 文件上传 + AI预置补充资料 → 个性化知识库
- 实现**三问认知引擎**（显性三步骤）：
  - 第一问：核心心智模型提取 + 动态知识图谱（Canvas绘制）
  - 第二问：学术争议挖掘 + 认知地图（共识/争议/未知三区）
  - 第三问：布鲁姆6层级深度测试 + 苏格拉底追问链 + 评价报告
- 实现**学习进度追踪**：进度条、能力雷达图、评价报告（三维度：概念理解/批判思维/实践迁移）
- 实现**数据持久化**：关系型数据库（RDB）存储课程、知识条目、问答记录、评价报告
- 演示课程：华为HCIA-AI认证（融合三门微认证内容）

## Capabilities

### New Capabilities

- `course-management`: 课程生命周期管理，包含创建（搜索框触发）、状态切换（未创建→已创建→活跃→完成）、卡片展示、排序、归档。演示课程为华为HCIA-AI认证。
- `knowledge-base`: 复合知识库构建，支持手动输入知识点、文件上传（PDF/Word/Markdown）、预置AI补充资料，三者融合形成个性化知识库并支持搜索。
- `three-question-engine`: 三问认知引擎核心，包含第一问（心智模型提取+知识图谱）、第二问（学术争议挖掘+认知地图）、第三问（布鲁姆6层级测试+苏格拉底追问链）。
- `evaluation-report`: 评价报告生成，包含三维度评分（概念理解/批判思维/实践迁移）、能力雷达图、问答原始记录、认知漏洞诊断及复习建议。

## Impact

- **代码**: 新建约20个.ets文件（7页面 + 6组件 + 4引擎/ViewModel + 4 DAO + 多个Model），修改现有 Index.ets 和 EntryAbility.ets
- **资源**: 新增字符串资源、颜色资源（深色/浅色主题）、页面路由配置
- **依赖**: 无需第三方依赖，全部使用HarmonyOS原生SDK API（`@ohos.data.relationalStore`, `@ohos.router`, `@ohos.file.picker`, `@kit.ArkUI` Canvas等）
- **数据库**: 新建6张RDB表（course, knowledge_item, question_block, test_item, evaluation_report, 预置数据初始化脚本内置在DatabaseHelper中）
